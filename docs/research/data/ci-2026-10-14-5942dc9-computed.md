## Learning: modes, stability, re-runs, cost and break-even

Source: learning.jsonl of each directory. Learnings: the warm-up's (round 0) and one from scratch in each timed round. The timed learned runs use the state of the warm-up learning (as ablation-report.cjs states; the run records confirm it: e.g. ark-ui ran react split in all 5 timed runs while learnings 2-4 chose all isolated); the per-round learnings measure stability and cost. Modes: per learning, in round order (CLI: the projects split, or "all isolated"). Mode agreement: share of learnings choosing the most common mode. Jaccard: mean pairwise similarity of the leaky (isolated) file sets. Timed runs: the mode each timed run used (the mode field of the run record), files re-run by the safety net and new leaky files, summed. Cost: median over learnings of the whole learning time minus its isolated run (seconds - t_iso; = t_sh + t_split where both are recorded), "k of n" learnings with both seconds and t_iso. Break-even: cost / (median isolated run - median learned run) from timing-ci.csv, the isolated run being the same DOM's default; the cost includes every split run of the learning (up to 4). Split runs per learning: (seconds - t_iso - t_sh) / t_split, rounded, where t_split is the last split run's time (an estimate: earlier split runs may take longer or shorter).
